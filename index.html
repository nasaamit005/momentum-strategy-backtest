Research Methodology & Technology

The repository includes Python backtesting code, performance and risk analysis, transaction-cost sensitivity, out-of-sample evaluation, generated HTML reports, and automated tests. Use the methodology report and source code to verify the specific assumptions and calculations.

Python Pandas NumPy Plotly Backtesting Risk Analytics Transaction Costs Out-of-Sample Testing Pytest Git & GitHub
Important: Historical backtest results do not guarantee future performance. Results depend on the data, assumptions, trading costs, and validation methodology. This project is for research and educational purposes, not investment advice.
